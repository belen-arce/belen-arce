# belen-arce_presentacion
# ¡Hola! Soy Belén&#x20;

**Sociología | Investigación social | Análisis de datos**

Soy estudiante de Sociología en la Pontificia Universidad Católica del Perú (PUCP), con experiencia en investigación social, procesamiento de datos y metodologías cualitativas y cuantitativas.

Me interesa comprender cómo las estructuras sociales, las instituciones y las experiencias cotidianas se relacionan, así como explorar las posibilidades del análisis de datos para investigar problemas sociales.

### Áreas de interés

- Investigación social y metodologías de investigación
- Desigualdades sociales y políticas públicas
- Análisis cuantitativo y cualitativo
- Investigación aplicada y experiencia de usuario

### Herramientas

**R · RStudio · ATLAS.ti · Git · GitHub**

### Proyecto destacado

[**Procesamiento de datos sobre ollas comunes y condiciones de vida con ENAHO 2024**](https://github.com/belen-arce/PC3_Bel-n_Arce)

Proyecto desarrollado en colaboración con Damián Tapia. Integra microdatos de la ENAHO 2024 mediante R y documenta procedimientos de limpieza, integración, exploración y clasificación de datos.
